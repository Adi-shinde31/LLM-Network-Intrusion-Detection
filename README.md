# 🧠 Network Traffic Classification using Machine Learning

This research project aims to build a **Machine Learning-based Intrusion Detection System (IDS)** that classifies **malicious and non-malicious network traffic**.  
The system is first trained and validated on the **CICIDS2017 dataset** and later extended to **live network data** captured in real time.

---


## 🎯 Project Objectives

1. **Preprocess and clean** the CICIDS2017 dataset (remove missing values, duplicates, and outliers).  
2. **Integrate all CSV files** into a single structured database (PostgreSQL or MongoDB).  
3. **Extract and engineer features** from network flow data for ML models.  
4. **Train and evaluate** machine learning models to classify traffic (malicious vs. benign).  
5. **Transition to live network traffic**, capturing and classifying in real time.  
6. **Deploy the trained model** as an API service for live prediction.

---

## 🧩 Technologies Used

- **Programming Languages:** Python, R  
- **Data Processing:** pandas, NumPy, scikit-learn  
- **Visualization:** Matplotlib, Seaborn  
- **Databases:** PostgreSQL / MongoDB  
- **Network Tools:** tcpdump, Scapy, Wireshark  
- **Model Deployment:** Flask / FastAPI  
- **Version Control:** Git, GitHub  

---

## 🧪 Expected Outcome

- A machine learning model that accurately distinguishes between **malicious** and **non-malicious** network traffic.  
- A ready pipeline for **real-time intrusion detection** once live data is introduced.  
- Scalable and modular folder structure for research and deployment.
